Звіт Практична робота 4 (Варіант 4)
Тема: Дослідження продуктивності malloc/free при різній кількості потоків.

1. Мета: Дослідити вплив конкуренції за глобальну купу на швидкість виконання операцій виділення пам'яті.

2. Хід роботи:

Написано бенчмарк для вимірювання часу мільйона викликів malloc/free.

Запущено тести для 1, 2, 4 та 8 потоків.

Проаналізовано залежність часу від кількості потоків.

3. Результати: 

Тестування з 1 потоками... Час виконання: 0.0129 секунд
Тестування з 2 потоками... Час виконання: 0.0281 секунд
Тестування з 4 потоками... Час виконання: 0.0614 секунд
Тестування з 8 потоками... Час виконання: 0.2003 секунд

Спостереження: Час виконання при збільшенні потоків зростає через блокування доступу до глобальної купи (heap contention).

4. Висновок: Стандартний malloc не є ідеально паралельним. Для високих навантажень краще використовувати спеціалізовані аллокатори (jemalloc, tcmalloc) або пули пам'яті.
